Monitoring Expansion : Installation & Setup

Created by Bram Verkuijlen, last modified on dec 17, 2025

This section provides all necessary instructions to prepare the environment and get the monitoring Proof of Concept (POC) running. It is intended for developers, engineers, or anyone setting up the POC for testing or demonstration purposes.

Overview

The POC pipeline includes the following components:

  • OTCM (OpenText Content Management System) – source of logs, metrics, and trace-like data

  • Fluent Bit – lightweight log shipper to collect OTCM logs and system events

  • OpenTelemetry Collector – central pipeline to process, transform, and export logs and metrics

  • Prometheus & Loki – optional backends for storing metrics and logs

  • Grafana – optional visualization layer for dashboards

Notes

  • Grafana is optional but recommended for visualizing logs and metrics. It can be installed on the same VM or a separate host.

  • This POC is tested on Windows 24.4; other OS configurations are out of scope.

  • The focus is on understanding monitoring possibilities of enterprise ECM systems using OTCM; full integration into production systems or AMI is out of scope.
