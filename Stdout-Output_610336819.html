Monitoring Expansion : Stdout Output

Created by Bram Verkuijlen, last modified on dec 19, 2025

Config file: outputs/stdout.conf

This output configuration is used to print all ingested logs to the console or standard output. It is primarily useful for testing, debugging, or verifying that Fluent Bit is correctly reading and parsing logs.

Table of Contents

  • Output configuration
  • Explanation
  • Use case

Output configuration

[OUTPUT]
    Name              stdout
    Match             *
    Format            json_lines
    json_date_format  iso8601
    json_date_key     utc_timestamp
    workers           5

Explanation

Setting

Purpose

Name stdout

Sends logs to the console/standard output for debugging or monitoring purposes

Match *

Matches all logs regardless of tag

Format json_lines

Converts log entries to JSON, one per line, for readability and structured output

json_date_format iso8601

Formats timestamps in ISO 8601 format

json_date_key utc_timestamp

Field name used for the timestamp in the JSON output

workers 5

Number of parallel threads used to process output events, improving throughput

Use case

  • Quick validation of input configuration, parsing, and filters

  • Debugging Fluent Bit pipelines before sending logs to a remote endpoint

  • Useful in development or POC environments where logs are not yet forwarded externally
