Purpose / Overview

SQL Connect Logs track database connection activity and SQL query execution within the Content Server. They record:

  • When connections are opened and closed

  • Execution of SQL queries

  • Database-related warnings or errors

These logs are critical for:

  • Analyzing database performance and detecting bottlenecks

  • Monitoring connection reliability and timeouts

  • Troubleshooting query execution issues

Key Fields & Metrics

Field

Description / Metric

Timestamp

Date and time of the log entry

Level

Log severity (INFO, WARN, ERROR, DEBUG, TRACE)

Thread ID / Sequence

Identifies the thread or query sequence

Message

Detailed description of the database action or error

Query / SQL Details

Executed SQL query and parameters, if present

Log ID / Request Time

Internal request identifier or duration in milliseconds

Relevance

SQL Connect Logs are great for database observability and troubleshooting.

Aspect

Value

Troubleshooting

★★★★☆ – Direct insight into connection errors and query failures

Functional insight

★★★☆☆ – Shows which database actions are occurring and by which threads

Performance metrics

★★★★☆ – Useful for tracking query execution times and connection patterns

Correlation value

★★★★☆ – Best analyzed alongside Thread Summary Timing Logs and Thread Logs

Correlation

SQL Connect Logs are especially valuable when correlated with:

  • Thread Summary Timing Logs – to identify whether SQL queries are causing slow requests
    Thread Summary Timing Logs

  • Thread Logs – to understand database-related errors in context of server thread execution
    Thread Logs

  • Web Server Client Timing Logs – to connect long-running queries with frontend request delays

  • Web Server Client Timing Logs

Observability Context

  • Logs contain raw database activity – high volume; filtering by thread or SQL type is recommended

  • Helps detect connection leaks, repeated failed queries, and latency issues

  • Can be parsed into metrics for database load, query durations, and error frequency
