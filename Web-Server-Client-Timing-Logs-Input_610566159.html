Monitoring Expansion : Web Server Client Timing Logs Input

Created by Bram Verkuijlen, last modified on dec 19, 2025

Config file: inputs/ot_timing_ctl_logs.conf

This configuration ingests Web Server Client Timing Logs from OTCM.
These logs capture detailed request timing information between the web server and Content Server, including execution time, response time, and per-request metrics.

For detailed fields, examples, and metrics, refer to the Web Server Client Timing Logs documentation page.

Input configuration

# Opentext Web Server Client Timing Logs
# Configured in OTCM via:
# http://<OTCM-HOST>/OTCS/cs.exe?func=admin.configurelogging

[INPUT]
    Name       tail
    db         C:\Monitoring Expension\Fluent Bit\db\timingctllogs.db
    Path       C:\OPENTEXT\OTCS\logs\timing_logs\llclient*
    Path_Key   file
    tag        cs.timingctllogs
    skip_long_lines on

Explanation

Setting

Explanation

Name tail

Reads log files from disk and follows them as they grow

db

Stores file offsets to prevent duplicate ingestion after restarts

Path

Location of OTCM Web Server Client Timing Logs

Path_Key file

Adds the source file path to each record

tag cs.timingctllogs

Identifies timing log events for filtering and routing

skip_long_lines on

Prevents Fluent Bit from crashing on unusually long lines

Metadata enrichment filter

[FILTER]
    Name   modify
    Match  cs.timingctllogs

    Add applicationID -
    Add applicationVersion 24.4
    Add company opentext
    Add componentCode timings
    Add level INFO
    Add logger -
    Add message -
    Add server Opentext-xECM-f:2099
    Add serviceCode xecm

Explanation

Adds static metadata to each log entry to ensure consistency across log types and compatibility with downstream observability tooling.

Parsing filter

[FILTER]
    Name         parser
    Match        cs.timingctllogs
    Key_name     log
    Parser       timingctllogs_parser
    Reserve_Data True

Explanation

Parses raw CSV log lines into structured fields using a regex parser.

Setting

Explanation

Key_name log

Field containing the raw log line

Parser timingctllogs_parser

Custom parser for Web Server Client Timing Logs

Reserve_Data True

Keeps original fields alongside parsed values

Type conversion filter

[FILTER]
    Name type_converter
    Match cs.timingctllogs
    str_key ExecTime ExecTime int
    str_key ResponseTime ResponseTime int

Explanation

Converts selected fields from strings to integers for metric aggregation.

Field

Purpose

ExecTime

Total execution time of the request (converted to int)

ResponseTime

Total response time (converted to int)

Parser definition

Config file: parsers.conf

[PARSER]
    Name   timingctllogs_parser
    Format regex
    Regex  ^(?<Date>[0-9]{1,2}/[0-9]{1,2}/[0-9]{4}),(?<Time>[0-9]{2}:[0-9]{2}:[0-9]{2}(?:\.[0-9]{1,3})?),(?<FuncAction>[A-Za-z0-9_.]+),(?<IP>(?:[0-9]{1,3}(?:\.[0-9]{1,3}){3}|::1|[A-Fa-f0-9:]+)),(?<ExecTime>[0-9?]+),(?<AcceptTime>[0-9?]+),(?<ServerTime>[0-9?]+),(?<ResponseTime>[0-9?]+),(?<ObjectId>[0-9?]+),(?<ResponseSize>[0-9?]+),(?<ServerName>[A-Za-z0-9_.-]+),(?<RequestID>[0-9a-fA-F-]{36})$
    Time_Key Time
    Time_Format %H:%M:%S.%L

Explanation

The parser converts CSV log lines into structured key/value fields for downstream processing.

Element

Purpose

Regex

Matches the CSV format of Web Server Client Timing Logs

Time_Key

Field to use as the timestamp for each record

Time_Format

Format for parsing the timestamp
