Monitoring Expansion : System Monitoring input

Created by Bram Verkuijlen, last modified on dec 19, 2025

Configuration file: inputs/ot_monitoring.conf

This Fluent Bit input is used to ingest OTCM System Monitoring events.
For a detailed explanation of the event structure, fields, and use cases, refer to the System Monitoring Logs documentation page.

Configuration

# Opentext monitoring logs
# Configured in OTCM via:
# http://<OTCM-HOST>/OTCS/cs.exe?func=admin.FluentBitConfig

[INPUT]
    Name   tcp
    Format json
    Listen 127.0.0.1
    Port   5170
    tag    cs.systemmonitoring

explanation

Setting

Explanation

Name tcp

Uses the TCP input plugin to receive log events pushed by OTCM

Format json

System Monitoring events are emitted by OTCM in JSON format

Listen 127.0.0.1

Fluent Bit listens only on the local interface

Port 5170

Default port used by OTCM to send System Monitoring events

tag cs.systemmonitoring

Tag used to identify and route System Monitoring logs
