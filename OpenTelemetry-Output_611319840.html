Monitoring Expansion : OpenTelemetry Output

Created by Bram Verkuijlen, last modified on dec 19, 2025

Config file: outputs/otlp.conf

This output configuration forwards all ingested logs to a remote endpoint (in this POC, the OpenTelemetry Collector). It is used to integrate logs into an observability pipeline for centralized collection, processing, and analysis.

Output configuration

[OUTPUT]
    Name   forward
    Match  *
    Host   127.0.0.1
    Port   8006

Explanation

Setting

Purpose

Name forward

Sends logs to a remote Fluent Bit or Fluentd forward endpoint

Match *

Matches all logs regardless of tag

Host 127.0.0.1

Target host where the OpenTelemetry Collector (or other forward-compatible service) is running

Port 8006

TCP port used by the collector to receive log data

Use case

  • Centralized collection of all OTCM logs for observability

  • Integration with OpenTelemetry pipelines for further processing and metrics extraction

  • Useful in production environments to offload logs from individual servers
