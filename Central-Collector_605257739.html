Monitoring Expansion : Central Collector

Created by Bram Verkuijlen, last modified on dec 29, 2025

Collector distribution: OpenTelemetry Collector Core
https://github.com/open-telemetry/opentelemetry-collector

This configuration is for the Central Collector used in the Monitoring Expansion POC. It aggregates logs and metrics from Fluent Bit and other collectors, processes them, and exports them to Loki (logs) and Prometheus (metrics).
Loki Prometheus

For detailed information about input logs and metrics, refer to their respective documentation pages.

Receivers

Receivers define how telemetry enters the collector.

receivers:
  otlp:
    protocols:
      grpc:
        endpoint: 0.0.0.0:8895
      http:
        endpoint: 0.0.0.0:8896
        cors:
          allowed_origins:
           - "http://*"
           - "https://*"

Explanation

Setting

Purpose

otlp

OTLP receiver, accepts telemetry in OTLP format

protocols.grpc.endpoint

GRPC port for OTLP ingestion

protocols.http.endpoint

HTTP port for OTLP ingestion

cors.allowed_origins

Allows browser-based requests from these origins

Processors

Processors transform, batch, or enrich telemetry before export.

processors:
  batch:
    timeout: 5s
    send_batch_size: 1024
    send_batch_max_size: 8192

Explanation

Setting

Purpose

batch

Groups telemetry to improve performance and reduce network load

timeout

Maximum time to wait before sending batch

send_batch_size

Number of records per batch

send_batch_max_size

Maximum batch size

Other processors like filtering, enrichment, or metric manipulation can be added as needed.

Exporters

Exporters define where the telemetry is sent.

exporters:
  debug:
    verbosity: detailed
  prometheus/metrics:
    endpoint: "0.0.0.0:9466"
    namespace: "OTCM"
    send_timestamps: true
    enable_open_metrics: true
    resource_to_telemetry_conversion:
      enabled: true
    translation_strategy: "UnderscoreEscapingWithSuffixes"
    metric_expiration: 10m
  otlphttp/logs:
    endpoint: "http://127.0.0.1:3100/otlp"
    tls:
      insecure: true

Explanation

Exporter

Purpose

debug

For debugging: prints telemetry to console

prometheus/metrics

Exposes metrics for Prometheus scraping

otlphttp/logs

Sends logs to Loki or other OTLP endpoints

Pipelines

Pipelines define how telemetry flows through receivers, processors, and exporters.

service:
  telemetry:
    metrics:
      readers:
        - pull:
            exporter:
              prometheus:
                host: '0.0.0.0'
                port: 8892

  pipelines:
    metrics:
      receivers: [otlp]
      processors: [batch]
      exporters: [prometheus/metrics]
    logs:
      receivers: [otlp]
      processors: [batch]
      exporters: [debug, otlphttp/logs]

Explanation

Pipeline

Purpose

metrics

Processes OTLP metrics, batches them, and exposes via Prometheus

logs

Processes OTLP logs from Fluent Bit or other collectors, batches them, and exports to debug and Loki

readers.pull

Prometheus scraping configuration
