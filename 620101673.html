Monitoring Expansion : POC Port & Folder Structure Compatibility

Created by Bram Verkuijlen on dec 29, 2025

Issue Description
The POC relies on specific ports and folder paths for the components (Collectors, Loki, Prometheus, Fluent Bit). On other systems, conflicts may occur due to:

  • Duplicate or in-use ports (e.g., OTLP, Prometheus, Loki endpoints)

  • Different folder structures or missing directories for log storage and configuration

These issues may prevent the POC from running without manual adjustments.

Impact

  • POC may fail to start if ports are already in use

  • Logs may not be collected or metrics may not be exposed correctly if folder paths differ

  • Component connectivity could break if endpoints are modified

Planned Mitigations

  • Implement a main config.yml to centralize port and folder configuration

  • Make the folder structure loosely coupled to allow flexibility across different systems

  • Include validation checks to detect port conflicts and missing directories at startup

Status / Notes

  • This issue is documented and planned for future improvements in the Roadmap & Improvements section
    Roadmap & Improvements

  • Due to time constraints during the internship, no fixes have been applied yet

  • Cross-platform testing (Linux, different Windows versions) is still to be performed
