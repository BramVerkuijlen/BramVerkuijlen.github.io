Monitoring Expansion : Histogram Buckets – Function Action Timings

Created by Bram Verkuijlen on dec 29, 2025

Issue Description
The histogram buckets of the function action timings do not appear to map timing values correctly. As a result, timing metrics visualized in Grafana may be inaccurate.

Possible Cause
The custom histogram bucket configuration in the Log Metrics Collector may not align with the actual timing values produced by OTCM. Bucket ranges or mapping logic could be misconfigured.

Impact

  • Dashboards showing request timings may display misleading distributions.

  • Analysis of system performance could be affected.

  • Correlations with other metrics might be inconsistent.

Notes / Next Steps

  • Investigate the current histogram bucket configuration in the Log Metrics Collector.

  • Test alternative bucket ranges or aggregation methods.

  • Determine if adjustments can fix the mapping or if a different metric collection approach is needed.
