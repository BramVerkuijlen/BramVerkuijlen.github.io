Monitoring Expansion : Components

Created by Bram Verkuijlen, last modified on dec 17, 2025

This section describes the core components of the monitoring Proof of Concept (POC) pipeline for OTCM. Each component is documented with its purpose, role in the architecture, and links to detailed setup and configuration guides.

  • Overview

Overview

Component

Description

OTCM (OpenText Content Management)

Source of logs, metrics, and trace-like information from the content server.

Fluent Bit

Lightweight log shipper that collects OTCM logs and system events and forwards them to OpenTelemetry Collector.

OpenTelemetry Collector

Central pipeline for processing, transforming, and exporting logs and metrics to downstream systems.

Prometheus

Optional backend for storing and scraping metrics, supports long-term analysis.

Loki

Optional backend for storing logs in a centralized and queryable format.

Grafana

Visualization layer for dashboards, metrics, and logs. Can be installed on the same VM or on a separate host.

Notes

  • Each component has its own configuration nuances and requirements; see the individual subpages for detailed instructions.

  • The hub page is intended as a quick navigation guide and overview.

  • Optional components (Prometheus, Loki, Grafana) are not strictly required for the pipeline to function but provide long-term storage and visualization capabilities.

  • The pipeline is modular: components can be replaced or upgraded without major redesign.
