Monitoring Expansion : Thread Summary Timing Logs Input

Created by Bram Verkuijlen, last modified on dec 19, 2025

Config file: inputs/ot_timing_thread_logs.conf

This configuration ingests Thread Summary Timing Logs from OTCM.
These logs provide detailed timing information for server threads, including request execution time, SQL execution metrics, queue time, and thread-level performance indicators.

For full details on fields, examples, and metrics, refer to the Thread Summary Timing Logs documentation page.

Input configuration

# Opentext Thread Summary Timing Logs
# Configured in OTCM via:
# http://<OTCM-HOST>/OTCS/cs.exe?func=admin.configurelogging

[INPUT]
    Name       tail
    db         C:\Monitoring Expension\Fluent Bit\db\timingthreadlogs.db
    Path       C:\OPENTEXT\OTCS\logs\timing_logs\timings*
    Path_Key   file
    tag        cs.timingthreadlogs
    skip_long_lines on

Explanation

Setting

Explanation

Name tail

Reads log files from disk and follows them as they grow

db

Stores file offsets to prevent duplicate ingestion after restarts

Path

Location of OTCM Thread Summary Timing Logs

Path_Key file

Adds the source file path to each record

tag cs.timingthreadlogs

Identifies thread timing log events for filtering and routing

skip_long_lines on

Prevents Fluent Bit from crashing on unusually long lines

Metadata enrichment filter

[FILTER]
    Name   modify
    Match  cs.timingthreadlogs

    Add applicationID -
    Add applicationVersion 24.4
    Add company opentext
    Add componentCode timings
    Add level INFO
    Add logger -
    Add message -
    Add server Opentext-xECM-f:2099
    Add serviceCode xecm

Explanation

Adds static metadata to each log entry for consistency and downstream processing.

Parsing filter

[FILTER]
    Name         parser
    Match        cs.timingthreadlogs
    Key_name     log
    Parser       timingthreadlogs_parser
    Reserve_Data True

Explanation

Parses raw CSV log lines into structured fields using a regex parser.

Setting

Explanation

Key_name log

Field containing the raw log line

Parser timingthreadlogs_parser

Custom parser for Thread Summary Timing Logs

Reserve_Data True

Keeps original fields alongside parsed values

Parser definition

Config file: parsers.conf

[PARSER]
    Name   timingthreadlogs_parser
    Format regex
    Regex  ^(?<Date>[^,]+),(?<Time>[^,]+),(?<StartTick>[^,]+),(?<Thread>[^,]+),(?<UserName>[^,]+),(?<IP>[^,]+),(?<FunctionAction>\"(?:[^\"]|\"\")*\"|[^,]*),(?<ExecTime>[^,]+),(?<SQLTime>[^,]+),(?<SQLCount>[^,]+),(?<GenerateOutputTime>[^,]+),(?<ObjectID>[^,]*),(?<ParentID>[^,]*),(?<ContextUserName>[^,]+),(?<ReqSQLTime>[^,]+),(?<ReqSQLTimeLogged>[^,]+),(?<ReqSQLCountLogged>[^,]+),(?<MiscArgs>\"(?:[^\"]|\"\")*\"|[^,]*),(?<error>[^,]*),(?<StartMicro>[^,]+),(?<EndMicro>[^,]+),(?<EndTick>[^,]+),(?<StartClock>[^,]+),(?<EndClock>[^,]+),(?<ApplCtx>\"(?:[^\"]|\"\")*\"|[^,]*),(?<NRecs>[^,]+),(?<ReqNRecsLogged>[^,]+),(?<QueueTime>[^,]+),(?<TimingTick>[^,]+),(?<TimingMicro>[^,]+),(?<TimingClock>[^,]+),(?<QueueDepthIn>[^,]+),(?<QueueDepthOut>[^,]+)$
    Time_Key Time
    Time_Format %H:%M:%S

Explanation

Converts CSV log lines into structured key/value fields for ingestion and metric generation.

Element

Purpose

Regex

Matches the CSV format of Thread Summary Timing Logs

Time_Key

Field to use as the timestamp for each record

Time_Format

Format for parsing the timestamp
