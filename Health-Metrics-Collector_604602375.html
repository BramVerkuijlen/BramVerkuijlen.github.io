Monitoring Expansion : Health Metrics Collector

Created by Bram Verkuijlen, last modified on dec 29, 2025

Collector distribution: OpenTelemetry Collector Core
https://github.com/open-telemetry/opentelemetry-collector

This configuration is for the Health Metrics Collector used in the Monitoring Expansion POC.
It collects host-level metrics from the underlying Windows system on which Content Servers runs and forwards them to the Central Collector for aggregation and export to Prometheus.
Central Collector

These metrics provide metrics of the system health, resource utilization, and performance bottlenecks, independent of Content Servers application logs.

Receivers

Receivers define how telemetry enters the collector.

receivers:
  hostmetrics:
    collection_interval: 10s
    scrapers:
      cpu:
      memory:
      disk:
      filesystem:
      network:

The hostmetrics receiver is part of the OpenTelemetry Collector Core distribution.
It was chosen because it provides stable, low-overhead host and system metrics without requiring contrib components, making it suitable for both POC and future production use.
https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/receiver/hostmetricsreceiver/README.md

Explanation

Setting

Purpose

hostmetrics

Collects metrics from the local operating system

collection_interval

Interval at which host metrics are collected

cpu

CPU usage and load metrics

memory

Memory usage and availability

disk

Disk I/O performance

filesystem

Disk usage and free space

network

Network traffic and throughput

These scrapers provide visibility into system load, capacity, and resource pressure on the Windows host running OTCM.

Exporters

Exporters define where the telemetry is sent.

exporters:
  debug:
  otlp:
    endpoint: "127.0.0.1:8895"
    tls:
      insecure: true

Explanation

Exporter

Purpose

debug

Outputs collected metrics locally for troubleshooting

otlp

Sends host metrics to the Central Collector

The OTLP exporter forwards metrics to the Central Collector, where they are exposed to Prometheus.
Central Collector

Pipelines

Pipelines define how telemetry flows through receivers and exporters.

service:
  telemetry:
    metrics:
      readers:
        - periodic:
            exporter:
              otlp:
                protocol: http/protobuf
                endpoint: "127.0.0.1:8896"

  pipelines:
    metrics:
      receivers: [hostmetrics]
      exporters: [debug, otlp]

Explanation

Pipeline

Purpose

metrics

Collects host metrics and forwards them to the Central Collector

telemetry

Periodically exports internal telemetry to the central collector

This pipeline ensures that Windows host health metrics are continuously available for monitoring and alerting.
