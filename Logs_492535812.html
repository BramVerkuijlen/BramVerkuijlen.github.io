Monitoring Expansion : Logs

Created by Bram Verkuijlen, last modified on dec 19, 2025

This page provides a concise overview of all OTCM log types, their purpose, key metrics, relevance, and locations. Each log type has its own detailed page, but this table serves as a central reference for monitoring, performance analysis, and observability.

Thread Summary Timing Logs

Overview of server thread execution times, request durations, and SQL activity.

Exec. Time, SQL Time, SQL Count, Queue Time, GenerateOutput Time

★★★★★ – Ideal for performance dashboards, SQL monitoring, detecting bottlenecks

OPENTEXT\OTCS\logs\timing_logs\

CSV (timings*.csv)

Thread Logs

Detailed activity of individual server threads, including function calls, object initialization, errors, and warnings.

Timestamp, Level, Thread/Component, Message, User/Context

★★★★☆ – Useful for troubleshooting, understanding thread behavior

OPENTEXT\OTCS\logs\thread_logs\

Text (thread*.out)

SQL Connect Logs

Tracks database connection activity and SQL query execution, including errors and performance metrics.

Connection counts, Query execution, Query errors, Transaction start/commit/rollback, Request Time/Duration

★★★★☆ – Database load and reliability metrics

C:\OPENTEXT\OTCS\logs\connect_logs\

Text (connect*.out)

Trace Logs

Experimental or audit-focused traces of internal processes, stack frames, and feature tests; inconsistent and often verbose.

Thread, Depth, Status, Frame, ObjRef, Args/Locals/Stack

★☆☆☆☆ – Rarely useful in production, mainly for internal debugging or feature audits

C:\OPENTEXT\OTCS\logs\trace_logs\

Text (trace*.out)

Web Server Client Timing Logs

Records end-to-end request performance between web server and Content Server, including SQL timing and network delays.

Exec. Time, Accept/Server/Response Time, Object ID, Response Size-K, Request ID

★★★★★ – API performance dashboards, load analysis

C:\OPENTEXT\OTCS\logs\timing_logs\

CSV (llclient*.csv)

Web Server Client Logs

Functional and system details of requests via CGI/Servlet/IISAPI, including errors, socket communication, and request context.

Timestamp/Level, Request ID, Component/Action, Message, Configuration/Environment

★★★☆☆ – Error metrics, request volume, network troubleshooting

C:\OPENTEXT\OTCS\logs\cgi_logs\

Text (llclient*.out, llindeximport*.out)

Security Logs

Tracks authentication, authorization, and access events for auditing and compliance.

x-utc-timestamp, x-threadid, c-ip, x-authuser, c-func, cs-uri, time-taken, bytes, x-requestid

★★★★☆ – Security monitoring, access patterns, audit reporting

C:\OPENTEXT\OTCS\logs\security_logs\

Text (security*.log)

Java Logs

Logs Java class/method execution, JVM actions, and optionally system/network info. Configured via java.server.logging.properties.

Primarily for troubleshooting and deep JVM inspection, not for performance monitoring or dashboards.

Timestamp, Class & Method, Log Level, Message

★★☆☆☆ – Useful for debugging JVM behavior or startup issues, but limited value for monitoring, metrics, or dashboards

C:\OPENTEXT\OTCS\logs\

Text (otjava*.log.*)

System Monitoring Events

JSON events capturing system health, resource usage, alerts, and configuration changes. Collected via TCP listener.

applicationID, componentCode, eventType, level, message, server, serviceCode, thread, utc_timestamp

★★★☆☆ – Health monitoring, incident detection

TCP via Fluent Bit (port 5170)

JSON

Notes:

  • Relevance Ratings: ★★★★★ = Most useful for observability and metric extraction; ★ = minimal metric value.

  • Trace Logs: Not actively generated in the current POC environment.

  • Java Logs: Accessed via file system; not configurable through the Admin Panel.

  • System Monitoring Events: Captured by Fluent Bit, not written to local files.
