It is intended as a living document for tracking next steps and possible enhancements.

Short-Term Improvements

Main Configuration & Folder Structure Decoupling

  • Centralize ports, file paths, and other configurable parameters in a main config.yml

  • Make folder paths more flexible to allow easy deployment on different Windows systems

  • Ensure default configurations minimize conflicts with existing services

Enhanced Application Monitoring

  • Explore using a reverse proxy or API gateway to gather additional performance telemetry

  • Could provide deeper insights into request timings, throughput, and bottlenecks

  • Add to advice section for AmeXio use cases

Mid-Term Improvements

Linux Support & Java Agent

  • Investigate Linux deployment options for OpenText Content Server (xECM) or collectors

  • Evaluate if a Java agent can be installed for more granular metrics and traces

  • Test collectors, Prometheus, Loki, and Grafana on Linux systems

Trace & Log Restructuring

  • Explore reorganizing log-derived traces for better correlation with metrics

  • Improve histogram bucket accuracy and timing measurement

Long-Term Improvements

Containerization & Cloud Deployment

  • Evaluate running collectors, Prometheus, Loki, and Grafana in Docker or Kubernetes

  • Investigate cloud deployment options for scalability and resilience

  • Consider distributed deployment best practices for high availability

Security

  • Implement full security stack for production-grade deployment

  • Role-based access, TLS, authentication, and secure storage of telemetry

  • May also include auditing, logging, and alerting integration
