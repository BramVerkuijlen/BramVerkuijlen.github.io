Monitoring Expansion : Grafana

Created by Bram Verkuijlen, last modified on dec 29, 2025

This section documents Grafana as an optional component used for testing and visualizing telemetry in the Monitoring Expansion POC.

The goal of this part of the documentation is to describe:

  • How Grafana can be used to visualize telemetry collected by the POC

  • How it connects to Prometheus and Loki

  • Limitations and considerations for its use

Purpose

Grafana is used as a visualization and dashboard tool for the POC:

  • Displays metrics stored in Prometheus

  • Displays logs stored in Loki

  • Provides drilldowns and correlation between metrics and logs

Grafana is not required for the POC to function, but is recommended for monitoring and testing purposes.

Context

In this POC, Grafana has been used for testing dashboards and telemetry visualization:

  • Installed optionally on the same Windows VM as the POC, or on a separate host

  • No custom configuration is required; standard Grafana setup is sufficient

Grafana can read data from:

  • Prometheus – metrics backend
    Prometheus

  • Loki – log backend
    Loki

Key Responsibilities

  • Query metrics from Prometheus

  • Query logs from Loki

  • Provide dashboards and panels for visualization

  • Enable drilldowns from metrics to logs

Grafana does not:

  • Collect telemetry

  • Process or store logs/metrics

  • Require custom configuration for POC usage

Architecture Role

Grafana functions as an external visualization layer:
Architecture

  • Positioned downstream of Prometheus and Loki

  • Provides dashboards for testing and monitoring

  • Supports multi-source visualization for correlation

Limitations and Constraints

  • Grafana is optional and not part of the core POC

  • Requires network access to Prometheus and Loki

  • No custom dashboards are pre-configured; dashboards must be created manually if needed

Configuration

Deployment

  • Can be installed on the same host as the POC or on a separate host

  • Install using the official documentation
    https://grafana.com/docs/grafana/latest/setup-grafana/installation/

  • Dashboards can be created to visualize metrics and logs

  • Optional use: only needed for testing or demonstration of telemetry
